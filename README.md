## Ulam catalog

The authenticated dashboard loads recipe JSON from
[DummyJSON Recipes](https://dummyjson.com/recipes?limit=30) through
`lib/api_controller.dart`. The catalog maps recipe names, ingredients, cuisine,
preparation time, servings, and images into a searchable list. Displayed prices
are estimates based on serving count; they are not prices supplied by the API.
